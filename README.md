## ✨ 项目简介

Blockly Web Builder GPT 是一款 **AI 原生的可视化建站工具**。用户通过拖拽 Blockly 积木块定义页面结构与逻辑，GPT 引擎实时生成生产级前端代码，一键导出可直接部署的纯净源码包。

## 🛠️ 快速开始

1. 下载对应版本的 zip 包
2. 解压到任意目录
3. 用静态服务器打开 `index.html`

```bash
python -m http.server 8080   # 浏览器访问 http://localhost:8080
```
